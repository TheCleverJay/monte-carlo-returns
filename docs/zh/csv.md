# CSV 用法

## 日收益

```csv
date,return_pct,series
2024-01-02,0.12,demo
2024-01-03,-0.05,demo
```

也认：`return` / `日收益` / `收益率` / `日期` 等。

- 带 `%`、表头含 `pct`/`百分`/`收益率`、或 `|x| > 1` → 按**百分数**除以 100。
- 否则按**小数**（0.01 = 1%）。

## 净值

```csv
date,nav,series
2024-01-02,1.00000000,demo
```

也认：`净值` / `单位净值` / `equity` / `总资产` 等。日收益由相邻净值推导。

## 序列过滤

存在 `series` / `序列` / `名称` 列时：

```bash
mc-returns path.csv --series demo
```

## 编码

依次尝试 `utf-8-sig` / `utf-8` / `gb18030` / `gbk`。

## 明确不支持

券商持仓 dump、委托回报，以及没有 `日期 + (收益|净值)` 的格式。这是开源版的有意边界。
