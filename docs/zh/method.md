# 方法与局限

## 算法

1. 从 CSV 载入日简单收益 \(r_t\)（收益列，或由净值推导）。
2. 校验：至少 20 个可用样本（建议 ≥ 60），且样本波动不为 0。
3. 对 `sims` 条路径、每条 `years * 252` 个交易日，从袋子里**有放回**抽取 `r`。
4. 复利净值 `E ← E * max(0, 1+r)`，并跟踪路径上峰到谷回撤。
5. 把终值换算为 `years` 年年化收益，输出分位数（P5/P25/P50/P75/P95）、均值、亏损概率、最大回撤 &gt; 20% 的路径占比。

实现仅用标准库（`random.Random`，无 NumPy）。`--seed` 可复现同一袋子下的结果。

## 「重采样」在这里的含义

这是 **独立同分布的日频有放回重采样**，用于压力/教学，不是时间序列模型。

## 局限（引用数字前请读）

- 独立日抽取会**毁掉**自相关、波动聚集与崩盘聚集。
- 历史样本 ≠ 未来分布；状态切换对本工具不可见。
- 分位数描述的是**模拟袋子**，不是计量经济学意义上的预测置信区间。
- **不要**拿结果写保本承诺、做营销，或定实盘仓位。
- 每次成功运行，CLI 都会打印相应说明。

## 退出码

- `0`：模拟成功
- `1`：校验拒绝模拟（样本过少 / 波动为 0）
- `2`：CSV 无法解析 / 文件不存在
